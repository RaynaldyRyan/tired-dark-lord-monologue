A 100-word monologue for a fantasy villain who is secretly just very tired. Sarn, collector of the tomb-tax, waits on one heir's signature to legalise the dead — the weariness lives in his restarts, corrections and small deflections, never in saying so. `main.ts` (Node stdlib only) writes the monologue deterministically to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
